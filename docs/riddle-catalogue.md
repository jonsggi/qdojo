# Riddle catalogue — retired release direction

The 2026-09-21 combat pivot retires riddle catalogue expansion from the active
release. The previous catalogue is preserved in
[the riddle archive](archive/riddle-v0/docs/riddle-catalogue.md).

New community/training work should follow [NPCs](npcs.md),
[combat validation](model.md) and [the pivot plan](pivot-plan.md).
Existing riddle generators remain legacy code; their presence is not a plan
to combine canonical-answer scoring with combat.
