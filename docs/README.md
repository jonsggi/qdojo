# QDOJO docs

> **Purpose:** every document in one place, with a reading order for each kind of reader. \
> **Audience:** everyone. \
> **Status:** reference. \
> **Last verified:** 2026-09-25 (every active document is listed and every link resolves: `python3 docs/reference/check_docs.py`)

**Status words used in each document's header:** *normative* means it defines
behaviour and implementations must match it; *guide* explains how to do
something; *reference* describes or measures what exists; *historical* is kept
for the record and does not describe the current system.

## Pick your path

**Spectator.** Watch at [qdojo.jonsggi.com](https://qdojo.jonsggi.com/), then:
[glossary](glossary.md) → [the dojo](lore.md) → [combat rules](combat.md) §1–5 →
[competition](competition.md) §1.

**Bot builder.** [Build a bot](build-a-bot.md) → [glossary](glossary.md) →
[combat rules](combat.md) → [NPCs](npcs.md) → [developer API](api.md) §1–2 and §6.

**Contract and protocol reviewer.** [Architecture](architecture.md) →
[specification](spec.md) → [combat rules](combat.md) → [protocol](protocol.md) →
[matchmaking](matchmaking.md) → [competition](competition.md) →
[validation gates](model.md) → [validation status](validation-status.md) →
`contracts/*/README.md`.

**Operator.** [Architecture](architecture.md) → [operations](operations.md) §8 →
[roadmap](roadmap.md) → [product decisions](product-decisions.md) →
[legacy closeout](legacy-closeout.md) → [audit findings](../audits/README.md).
