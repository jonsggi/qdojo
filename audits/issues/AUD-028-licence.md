# AUD-028 — The repository has no licence

- **Status:** Open
- **Priority:** P1 — open-source release
- **Type:** Legal
- **Evidence:** No LICENSE file; builders cannot safely reuse the example planner
- **Scope:** Repository root

## Finding

Without a licence the public repository is all rights reserved by default ([product review](../reports/2026-09-25-product-review.md)).

## Acceptance criteria

- [ ] Choose a licence for the code (and separately for the artwork, see AUD-010).
- [ ] Add LICENSE and state it in the README.
